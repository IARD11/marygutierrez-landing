# TBEICI-MARY

Proyecto local para construir el universo creativo, estrategico y visual de TBEICI junto a Mary.

## Proposito

Este espacio sirve para ordenar decisiones de marca, direccion artistica, contenido, lanzamientos, referencias visuales y materiales editables del proyecto.

## Punto de partida

- Mary es artista musical y creadora de contenido.
- TBEICI necesita tratarse como proyecto artistico, no solo como cuenta de redes.
- La direccion 2026 debe sentirse mas fotografica, editorial, pulida y real.
- Ignacio funciona como productor, manager y apoyo estrategico.
- El contexto maestro actual suma una linea city girl, emocional, editorial y moderna para marca personal, servicios creativos y landing.

## Carpetas

- `00_contexto`: identidad, principios, briefs y notas base.
- `01_estrategia`: posicionamiento, brand bible, estrategia de plataformas.
- `02_contenido`: ideas, calendarios, guiones, captions y piezas.
- `03_visual`: direccion de arte, styling, moodboards y referencias.
- `04_lanzamientos`: planes por single, EP, campana o etapa.
- `05_referencias`: artistas, marcas, fotos, videos y fuentes de inspiracion.

## Archivos base

- `00_contexto/contexto_proyecto_tbeici_original.txt`: contexto original entregado por Ignacio.
- `00_contexto/CONTEXTO_OPERATIVO_TBEICI_MARY.md`: version ordenada para decisiones estrategicas, visuales y de contenido.
